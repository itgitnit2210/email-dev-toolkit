# Changelog

## 0.3.0

- Added `email-template` dynamic HTML IntelliSense completion using the current extension layout settings.
- Added `onLanguage:html` activation so dynamic email completions are available while editing HTML.
- Added quick aliases for `email-section`, `email-image`, and `email-button`.
- Added responsive column snippets for `email-columns`, `email-columns-6040`, `email-columns-4060`, and `email-columns-reverse`.
- Kept Command Palette generators for configurable/custom workflows.
- Updated documentation around the type-`email-` developer workflow.

## 0.2.0

- Reworked responsive architecture around fluid production mobile width.
- Added configurable desktop width, preview width, padding, and breakpoint settings.
- Added layout presets.
- Split commands, generators, config, email helpers, and validators into separate modules.
- Added configurable column, button, and responsive image generators.
- Added current-email validation command.
- Split static snippets into focused snippet files.
- Added syntax, snippet, terminology, and automated test checks.

## 0.1.0

- Initial project structure.
